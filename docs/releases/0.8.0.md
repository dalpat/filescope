# Filescope 0.8.0

Local file navigation, better Open/Save dialogs and safer transfers.
Wayland-only release for x86_64 Linux.

## What's new

- Reopen closed tabs with Ctrl+Shift+T. Optionally restore tab locations after
  restart, without restarting terminals or file operations.
- Use Ctrl+L to edit the path inside a compact header. Folder suggestions work
  in both the main window and Open/Save dialogs.
- Open/Save dialogs gain Back/Forward/Up, remembered folders per application,
  search, previews and file selection across several folders.
- Save suggests an extension without changing the filename automatically and
  checks the destination again before returning it to the calling application.
- Transfers show progress, cancellation and failure details. Retry Failed skips
  completed items and checks whether failed source files have changed.

## Fixes

- External Trash links open the Trash view.
- Missing recent files no longer leave gaps in This PC. Its sidebar entry has
  a separate group.
- Rename does not overwrite an existing destination. Copy/move checks protect
  changed files, preserve raw filenames and keep partial files private.
- Compress accepts dangling symlinks; local file URI schemes are case-insensitive.

## Supported release

- x86_64 Linux tarball for Wayland desktops. X11 is outside the support scope.
- Runtime requirements: glibc 2.39+, GTK 4.16+, libadwaita 1.5+ and VTE GTK4
  0.70+. In-app update downloads require curl.
- Native packages and Flatpak move to 0.9.0. Google Drive and saved network
  connections are not included. Ordinary system-mounted folders remain usable.
- The optional Open/Save integration stays disabled until enabled from the menu.

## Known issue and validation limits

- A terminal-link integration test fails for a quoted path containing spaces
  and Japanese characters. The cause is not confirmed; the issue is accepted for now.
- 211 default tests and 145 of 146 special tests passed. The remaining failure
  is the terminal-link test above. Special checks ran in private Broadway/D-Bus
  sessions; they do not prove native Wayland desktop behavior.
- Manual desktop and tarball install/upgrade acceptance are deferred.
- Disabling the optional picker or uninstalling may report a busy desktop portal
  because of background app sessions, even after dialogs and screen sharing stop.

## Check and extract

Keep the tarball and its checksum file together, then run:

```sh
sha256sum -c filescope-v0.8.0-x86_64-linux.tar.gz.sha256
tar -xzf filescope-v0.8.0-x86_64-linux.tar.gz
```

The archive includes the application, installer, desktop assets, README,
changelog and license. Installation is a separate user action.
