# Filescope 0.8.1

Fixed overlapping cards when expanding **Drives** in **This PC**. The fix was
verified on GTK 4.16.3 in a private GNOME Wayland session. [Issue #1](https://github.com/dalpat/filescope/issues/1)

## Update

Use **Check for Updates** in Filescope, or download the x86_64 Linux tarball
and its checksum together.

```sh
sha256sum -c filescope-v0.8.1-x86_64-linux.tar.gz.sha256
tar -xzf filescope-v0.8.1-x86_64-linux.tar.gz
```

Requires Wayland, glibc 2.39+, GTK 4.16+, libadwaita 1.5+ and VTE GTK4 0.70+.
See the previous release for known limitations. [Filescope 0.8.0](https://github.com/dalpat/filescope/releases/tag/v0.8.0)

To check the fix, open **This PC** in Grid view and collapse and reopen
**Drives**. The cards should stay in their sections.
