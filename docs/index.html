filescope

A file manager for your Linux desktop.

You open folders, look at files, and move them. One window. No accounts. No cloud.

People

Four jobs, one app

There is no admin and no client. The same person does these jobs.

Tidy up

Rename, new folder, peek, properties

Rename

Select one file. Press F2. Type the new name on the file itself.

New folder

Ctrl+Shift+N. It starts as “New Folder”. You can undo it.

Preview

Select a file. Press Space. Pictures and text show inside. Anything else shows a card. Space again closes it.

Properties

Right-click one item. See type, size, place, times, owner, and permissions. Folder size is counted in the background.

Pack files

Zip and extract

Extract HereRight-click a .zip, .tar, .7z, or .rar. It unpacks into a new folder with the archive’s name.
CompressSelect files. Right-click → Compress. Pick .zip, .tar.gz, or .tar.xz. One item uses its name. Many items become “Archive”.

The matching tool must already be installed. If it is missing, a toast tells you the name.

Handy

Terminal and bookmarks

Open a terminal here

Ctrl+. or the menu. It opens your terminal in this folder. It tries $TERMINAL, then common ones such as ptyxis, GNOME Console, and gnome-terminal.

Bookmark this folder

Ctrl+D. It appears in the sidebar. The × removes it. Bookmarks live in ~/.config/filescope/bookmarks.

Next time

What it remembers

Look

Grid or list, zoom, sort, and whether hidden files are shown.

Window

Size, and whether it was maximized.

Bookmarks

Your own list. Missing folders are dropped on the next launch.

These sit in ~/.config/filescope/. Undo history is only for this run. Install with ./install.sh — it puts the app in your own folders, with no root. ./install.sh --uninstall removes it.
